Operating Systems

There are several ways of recognizing what kind of an operating system you have.

  1. The logo of a window like or or tells that you are on a Windows computer. A logo of tells you are using a Mac. The logo also shows up on the screen when you turn the device on.
  2. Special buttons exist only on Windows computers: Ctrl, Alt, and Windows ( or or ) keys and on Mac computers: Command () and Option () keys.

On Windows, you can tell what Windows version you have by either:

  1. Clicking Windows key + R, typing “winver”, and clicking OK to open a window that shows what the version is.
  2. Start button > search for “About your PC”.
  3. Start button > Computer > Properties (works on Windows 7).
  4. Start button > search for “System Information”.
