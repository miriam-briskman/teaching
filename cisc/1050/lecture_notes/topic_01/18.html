Computer Concepts: Software

    • Programs included in the Operating System are the Kernel (a core that includes instructions for the basic functionality,) Drivers (each of which provides service for and controls a specific type of device), and the User Interface (a means by which a user can interact with the computer: either graphically by clicking on the screen or textually by typing instructions.)
    • Examples of Operating systems are Windows, Mac OS, Chrome OS, and Linux.
  2. Utility software is also a type of a system software. Although not essential as the operating system, it helps in analyzing the computer’s behavior, debugging errors, and optimizing its operation. Examples of utility software are text editors, debuggers, antivirus programs, and file management programs (File Explorer, Finder, etc.)
  3. Application software (or user application software) are all the programs that let users complete daily tasks. This includes creating documents, playing games, listening to music, participating in online meetings, and sending emails.
    • Whether a piece of software is a system software or application software is hard to tell, and there are big debates and even court case decisions on this question.
    • The Office Suite (Word, PowerPoint, Excel, and Access) is Application software.
