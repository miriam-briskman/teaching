Using Word

Saving Word Documents

To save the document for the 1st time:

  1. Go to File → Save As → This PC,
  2. Type the name of the file in the name box,
  3. Choose the file type to be “Word Document (*.docx)” from the given file choices,
  4. Click the folder icon or name to choose the folder where to save the file,
  5. Click to save the file.

Alternative: Click the Save button on the Quick Access Toolbar and do steps 2 – 5 above.

To save an existing document, simply click the Save button on the Quick Access Toolbar or click Ctrl + S (Mac: Cmnd + S.)
