Using Word

Overview of Word Controls

  • Ribbon – the Control Center of Word
    • Tabs (Home, Insert, Draw, Design, Layout, References, Mailings, Review, View, and Help) → groups of commands → commands / buttons
    • Active (= currently selected) tab
    • Minimizing or collapsing the Ribbon
    • Special tool (contextual) tabs. Example: The Picture Tools Tab
    • Various items on the Ribbon: buttons, text boxes, and galleries
    • Some allow Live Preview of the design
    • Screen tips when hovering over buttons
    • Comparison: Dialog Box vs. Pane
